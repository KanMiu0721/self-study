# 与用户互动:
按钮通常使用 HTML` <button> `元素创建（有时也用 `<input>` 元素创建，type属性设置为如button或submit）。这些按钮是通用的——可以连接它们来触发任何功能，仅限于想象力和编程技能

表单通过诸如`<form>`、`<label>`、`<input>`和`<select>`等元素创建。表单元素可以用来创建比简单按钮更复杂的控制——例如，一个包含多个选项的下拉菜单，允许在不同主题中选择用户界面元素

然而，关键是，它们还可以用于创建表单，供用户在需要向网站服务器提交信息时填写

# 按钮:
按钮在网络上有几个主要用途。首先，它们用于触发功能，这在创建界面控件时非常有用。最简单的按钮是用以下代码实现的：
```
<button>Press me</button>
```
出现在标签之间的文字会在按钮内部渲染，浏览器会给它一些基本样式，使其默认看起来和表现得像按钮

## 形态的解剖结构
基本形式包含三点：

- 一个`<form>`元素，包裹所有其他表单内容。标签内的任何表单控件都是同一表单的一部分，提交表单时会包含它们的数据

- 一对或多对，分别由一个`<label>`元素和一个表单控制元素（通常是`<input>`元素组成，但也有其他类型，例如`<select>`）：

       1. 表单控制元素允许用户选择或输入一些数据，这些数据将在表单提交时发送到服务器
       2. `<label>`元素为表单控件提供一个识别标签，描述应输入的数据

- 一个`<button>`元素，用于提交表单

```
 <form action="./submit_page" method="get">
      <h2>Subscribe to our newsletter</h2>
      <p>
        <label for="name">Name (required):</label>
        <input type="text" name="name" id="name" required />
      </p>
      <p>
        <label for="email">Email (required):</label>
        <input type="email" name="email" id="email" required />
      </p>
      <p>
        <button>Sign me up!</button>
      </p>
    </form>
```

# `<form>`元素

`<form>`元素作为表单的外包，将所有表单控件归组其中。当按下`<button>`时，表单控件代表的所有数据都会提交到服务器。该元素可以有许多属性，但在示例中包含的两个最重要的属性如下：

- action： 包含一条通往我们想发送提交表单数据的页面的路径，以便处理。在提交表单后，会在网址中看到包含的内容。还会收到404错误回复，因为./submit_page页面实际上不存在，但目前没关系

- method： 指定想用来向服务器发送表单数据的数据传输方式。暂时别太担心;get值使数据作为附加参数发送到URL末尾
  
查看提交的数据
1. 进入另一个标签页的示例，尝试输入“Bob”这个名字和一个“bob@bob.com”的电子邮件地址。
2. 按下 `<button>`
action和method属性使表单数据以以下URL形式提交：
```
/some/url/submit_page?name=Bob&email=bob%40bob.com
```
## 结构形式:
可以在元素中包含任何你喜欢的HTML元素，来结构化表单元素本身，并提供容器用CSS来定位样式等

还可以把每个输入/标签对和提交按钮放在一个独立的`<p>`里，这样每个都会出现在不同的行里。这些元素默认都是内联的，这意味着如果不这样做，它们都会放在同一行上

有一个专门用于将形式元素分组的元素，称为`<fieldset>`。这在某些情况下非常有用，比如复杂表格以及将多个复选框和单选按钮分组时

# `<input>`元素:

`<input>`元素代表表格中输入的不同数据项
```
<input type="text" name="name" id="name" required />
```
- type： 指定要创建的表单控制类型。表单控制有许多不同类型，从简单的文本字段到单选按钮、复选框等。text会渲染一个基本的文本字段，可以接受任意值
- name(提供给服务器，可重复)： 指定数据项的名称。表格提交后，数据会以名称/值对的形式发送。在每种情况下，名称等于该属性值，值等于文本字段中输入的文本
- id（提供给前端代码，唯一）： 指定一个可用于识别元素的ID。在这种情况下，它用于将形式控制与其关联
- required： 指定必须在提交表单元素前输入一个值。这只应该设置在你需要的输入上，而不是可选字段

 要注意，有些输入类型通常不会直接从输入字段的文本中获得其值。例如，`<input type=“color”>`渲染一个颜色选择器控件，而`<input type=“radio”>`渲染一个可以选择或不选择的单选按钮控件 

 对于单选按钮，通常需要提供如果在特定属性中选择时提交的值。注意你可以在输入类型上指定属性，比如text和color——效果是该值在首次渲染时会预先填充到表单字段中
 
##  required以及实际的属性value
试着编辑表单，把value="Bob"写在第一个输入里。当重新加载代码时，会看到第一个字段默认输入了一个“Bob”的值

## 专用文本字段输入
有几种专门的文本字段输入类型专门用于处理特定类型的数据——`<input type=“number”>`，`<input type=“password”>`，`<input type=“tel”>`等。

# `<label>`元素
`<label>`元素为表单控件提供了识别标签，描述应输入的数据。可以在元素里放任何你喜欢的文本内容，但它们应该准确描述表单控制对应的数据。关联通过赋予表单控件一个属性，然后赋予元素一个与控件值相同的属性来创建
```
<label for="name">Name (required):</label>
<input type="text" name="name" id="name" required />
```

## 显式与隐式形式标签:
上面看到的表单标签样式称为显式表单标签——控制和标签之间的关联通过属性显式实现。也可以通过将控件嵌套在标签内来实现隐式表单标签
```
<label>
  Name (required):
  <input type="text" name="name" required />
</label>
```
