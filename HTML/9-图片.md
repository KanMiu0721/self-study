# 如何在网页上放置图片
为了在网页上放置图片，使用<img>元素。这是一个空元素（意味着它不能有子内容且不能有结束标签），需要两个属性才能有用：src和alt。src属性包含指向嵌入页面的图片的URL。与<a>元素的href属性类似，该属性可以是相对URL或绝对URL。没有src属性，img元素就没有图像可加载

如果图片叫做dinosaur.jpg，并且它和HTML页面在同一个目录里，可以像这样嵌入图片：

    <img src="dinosaur.jpg" alt="Dinosaur" />

如果图片在images子目录中，而子目录和HTML页面在同一目录里，那么可以这样嵌入它：
```
<img src="images/dinosaur.jpg" alt="Dinosaur" />
```
也可以使用其绝对URL嵌入图片
```
<img src="https://www.example.com/images/dinosaur.jpg" alt="Dinosaur" />
```

>不过，不建议通过绝对链接链接。应该托管想在网站上使用的图片，简单来说就是**把网站的图片和HTML放在同一服务器上**。此外，使用相对URL比绝对URL在维护上更高效（当将网站迁移到不同域名时，不需要更新所有URL以包含新域名）。在更高级的设置中，可能会使用CDN（内容分发网络）来传输图片
为
像`<img>`和`<video>`这样的元素有时被称替换元素。这是因为元素的内容和大小是由外部资源（如图像或视频文件）定义的，而非元素本身的内容

## 替代文本
alt的价值是图像的文字描述，适用于图像无法被看到/显示，或者由于网络速度慢而渲染时间较长的情况
```
<img
  src="images/dinosaur.jpg"
  alt="The head and torso of a dinosaur skeleton;
          it has a large head with long sharp teeth" />

```
测试文本最简单的方法是故意拼错文件名。如果图片名称拼写错误，浏览器不会显示图片，而是显示替代文本

## 宽度与高度

可以用width和height属性来指定图片的宽度和高度。它们以无单位的整数形式表示，表示图像的宽度和高度（像素单位）
