# 如何在网页上放置图片
为了在网页上放置图片，使用<img>元素。这是一个空元素（意味着它不能有子内容且不能有结束标签），需要两个属性才能有用：src和alt。src属性包含指向嵌入页面的图片的URL。与<a>元素的href属性类似，该属性可以是相对URL或绝对URL。没有src属性，img元素就没有图像可加载

如果图片叫做dinosaur.jpg，并且它和HTML页面在同一个目录里，可以像这样嵌入图片：

    <img src="dinosaur.jpg" alt="Dinosaur" />

如果图片在images子目录中，而子目录和HTML页面在同一目录里，那么可以这样嵌入它：
```
<img src="images/dinosaur.jpg" alt="Dinosaur" />
```
也可以使用其绝对URL嵌入图片
```
<img src="https://www.example.com/images/dinosaur.jpg" alt="Dinosaur" />
```

>不过，不建议通过绝对链接链接。应该托管想在网站上使用的图片，简单来说就是**把网站的图片和HTML放在同一服务器上**。此外，使用相对URL比绝对URL在维护上更高效（当将网站迁移到不同域名时，不需要更新所有URL以包含新域名）。在更高级的设置中，可能会使用CDN（内容分发网络）来传输图片
为
像`<img>`和`<video>`这样的元素有时被称替换元素。这是因为元素的内容和大小是由外部资源（如图像或视频文件）定义的，而非元素本身的内容

## 替代文本
alt的价值是图像的文字描述，适用于图像无法被看到/显示，或者由于网络速度慢而渲染时间较长的情况
```
<img
  src="images/dinosaur.jpg"
  alt="The head and torso of a dinosaur skeleton;
          it has a large head with long sharp teeth" />

```
测试文本最简单的方法是故意拼错文件名。如果图片名称拼写错误，浏览器不会显示图片，而是显示替代文本

## 宽度与高度

可以用width和height属性来指定图片的宽度和高度。它们以无单位的整数形式表示，表示图像的宽度和高度（像素单位）

这样做是有充分理由的。页面和图片的HTML是不同的资源，浏览器通过不同的HTTP（S）请求获取。一旦浏览器收到HTML，就会开始向用户显示。如果图片还没收到（通常情况会如此，因为图片文件大小通常比HTML文件大得多），浏览器只渲染HTML，并在收到图片后立即更新页面

```
<h1>Images in HTML</h1>

<img
  src="dinosaur.jpg"
  alt="The head and torso of a dinosaur skeleton; it has a large head with long sharp teeth"
  title="A T-Rex on display in the Manchester University Museum" />
<blockquote>
  <p>
    But down there it would be dark now, and not the lovely lighted aquarium she
    imagined it to be during the daylight hours, eddying with schools of tiny,
    delicate animals floating and dancing slowly to their own serene currents
    and creating the look of a living painting. That was wrong, in any case. The
    ocean was different from an aquarium, which was an artificial environment.
    The ocean was a world. And a world is not art. Dorothy thought about the
    living things that moved in that world: large, ruthless and hungry. Like us
    up here.
  </p>
  <footer>- Rachel Ingalls, <cite>Mrs. Caliban</cite></footer>
</blockquote>
```
浏览器下载HTML后，浏览器将开始显示该页面。

图片加载完成后，浏览器会将图片添加到页面。由于图片占用空间，浏览器必须将文字往下移动，以便将图片放在页面上方

这样移动文本对用户来说非常分心，尤其是当他们已经开始阅读时，而且还会导致浏览器重新渲染页面，这对性能很不利。

如果用和属性在HTML中指定图片的实际大小，浏览器就能知道图片在下载前该允许多少空间。

这意味着图片下载后，浏览器无需移动周围内容。

## 调整图像大小
如果图片尺寸设置得太大，图片看起来会颗粒感强、模糊或过小，下载不符合用户需求的图片会浪费带宽。如果不保持正确的宽高比，画面也可能出现变形。应该使用图片编辑器，先把图片调整到正确的尺寸，然后再把它放到网页上。

如果确实需要调整图片大小，应该用CSS。

## 图片标题
和链接一样，也可以为图片添加title属性，以便在需要时提供更多支持信息
```
<img
  src="images/dinosaur.jpg"
  alt="The head and torso of a dinosaur skeleton;
          it has a large head with long sharp teeth"
  width="400"
  height="341"
  title="A T-Rex on display in the Manchester University Museum" />
```

不过，这并不推荐——存在一些无障碍问题,最好将此类支持信息包含在主条目正文中，而不是附加在图片中

# 图像注释及图解:
可以用多种方式添加与图片相配的说明文字
```
<div class="figure">
  <img
    src="images/dinosaur.jpg"
    alt="The head and torso of a dinosaur skeleton;
            it has a large head with long sharp teeth"
    width="400"
    height="341" />

  <p>A T-Rex on display in the Manchester University Museum.</p>
</div>
```
但这里有个问题：没有任何语义上将图片与其说明联系起来，这可能会给屏幕阅读器带来麻烦

更好的解决方案是使用 HTML `<figure>` 和 `<figcaption>` 元素。这些图纸正是为此目的而创建：为图形提供语义容器，并清晰地将图形与说明文字关联起来。

```
<figure>
  <img
    src="images/dinosaur.jpg"
    alt="The head and torso of a dinosaur skeleton;
            it has a large head with long sharp teeth"
    width="400"
    height="341" />

  <figcaption>
    A T-Rex on display in the Manchester University Museum.
  </figcaption>
</figure>

```
`<figcaption>`元素告诉浏览器和辅助技术，说明文字描述了`<figure>`元素的其他内容


# CSS 背景图像:
可以用 CSS 把图片嵌入网页（JavaScript，但那是另一个故事）。CSS background-image 属性和其他属性用来控制背景图片的位置

要在页面的每个段落放置背景图片，可以这样做:
```
p {
  background-image: url("images/dinosaur.jpg");
}
```
>如果一张图片在内容上有意义，你应该使用HTML图片。如果图片纯粹是装饰，你应该使用CSS背景图片
