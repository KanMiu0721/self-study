# 表格上添加标题:
可以把表格放在`<caption>`元素里，然后嵌套在`<table>`元素里，给表格一个说明
```
<table>
  <caption>
    Dinosaurs in the Jurassic period
  </caption>
  <!-- … -->
</table>
```
# 用`<thead>`、`<tbody>`和`<tfoot>`来增加结构感

随着表格结构变得更复杂，赋予它们更多结构定义会很有用。一个明显的方法是使用`<thead>`、`<tbody>`和`<tfoot>`，这些工具可以让你为表格标记标题、正文和页脚部分


这些元素并不一定让屏幕阅读器用户更容易使用表格。它们本身不会带来视觉增强，但对于通过CSS进行样式和布局增强非常有用，可以提升可访问性

使用它们时，应按以下顺序排列：

- `<thead>`元素必须环绕表中作为头部的部分——通常是包含列标题的第一行，但这并不总是如此。如果你使用`<col>/<colgroup>`元素，表头应该会在这些元素下方。

- `<tbody>`元素需要包裹表内容中非表头或页脚的主要部分，并且应该在`<thead>`之后.

- `<tfoot>`元素需要包裹表格中作为页脚的部分，该元素应置于之后`<tbody>`
