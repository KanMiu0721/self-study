# 表格上添加标题:
可以把表格放在`<caption>`元素里，然后嵌套在`<table>`元素里，给表格一个说明
```
<table>
  <caption>
    Dinosaurs in the Jurassic period
  </caption>
  <!-- … -->
</table>
```
# 用`<thead>`、`<tbody>`和`<tfoot>`来增加结构感

随着表格结构变得更复杂，赋予它们更多结构定义会很有用。一个明显的方法是使用`<thead>`、`<tbody>`和`<tfoot>`，这些工具可以让你为表格标记标题、正文和页脚部分


这些元素并不一定让屏幕阅读器用户更容易使用表格。它们本身不会带来视觉增强，但对于通过CSS进行样式和布局增强非常有用，可以提升可访问性

使用它们时，应按以下顺序排列：

- `<thead>`元素必须环绕表中作为头部的部分——通常是包含列标题的第一行，但这并不总是如此。如果你使用`<col>/<colgroup>`元素，表头应该会在这些元素下方。

- `<tbody>`元素需要包裹表内容中非表头或页脚的主要部分，并且应该在`<thead>`之后.

- `<tfoot>`元素需要包裹表格中作为页脚的部分，该元素应置于之后`<tbody>`

# 作用域属性：
可以将scope属性添加到元素中，以准确告诉屏幕阅读器该单元格是哪个单元格的头部——例如，它是所在行的头部，还是列的头部
```
<thead>
  <tr>
    <th scope="col">Purchase</th>
    <th scope="col">Location</th>
    <th scope="col">Date</th>
    <th scope="col">Evaluation</th>
    <th scope="col">Cost (€)</th>
  </tr>
</thead>
<tr>
  <th scope="row">Haircut</th>
  <td>Hairdresser</td>
  <td>12/09</td>
  <td>Great idea</td>
  <td>30</td>
</tr>
```
scope还有另外两个可能的值——colgroup和rowgroup。这些标题用于叠加在多列或多行之上

# id 和 headers 属性
使用属性的另一种方法是使用 id 和 headers 属性来创建数据单元格与头部单元格之间的关联

一个元素可以为数据单元`<th>`提供标题，或者在更复杂的表中，为另一个头单元格提供标题。这允许你创建分层或分组的头部，其中一个头部描述多个其他头部

该属性用于将一个单元格或`<td>` ，与一个或多个头单元格链接。它使用一个空格分隔的字符串列表;字符串的顺序无关紧要。每个字符串必须匹配该单元所关联元素的唯一性
```
<thead>
  <tr>
    <th></th>
    <th></th>
    <th id="clothes" colspan="3">Clothes</th>
  </tr>
  <tr>
    <th></th>
    <th></th>
    <th id="trousers" headers="clothes">Trousers</th>
    <th id="skirts" headers="clothes">Skirts</th>
    <th id="dresses" headers="clothes">Dresses</th>
  </tr>
</thead>
<tbody>
  <tr>
    <th id="belgium" rowspan="2">Belgium</th>
    <th id="antwerp" headers="belgium">Antwerp</th>
    <td headers="belgium antwerp clothes trousers">56</td>
    <td headers="belgium antwerp clothes skirts">22</td>
    <td headers="belgium antwerp clothes dresses">43</td>
  </tr>
  <tr>
    <th id="ghent" headers="belgium">Ghent</th>
    <td headers="belgium ghent clothes trousers">41</td>
    <td headers="belgium ghent clothes skirts">17</td>
    <td headers="belgium ghent clothes dresses">35</td>
  </tr>
</tbody>
```
