# 可替换元素
图像和视频被描述为**可替换元素**。这意味着 CSS 不能影响它们的内部布局——而仅影响它们在页面上相对于其他元素的位置。但是，正如将看到的，CSS 可以对图像执行多种操作。

某些替换元素（例如图像和视频）也具有宽高比。这意味着它在水平（x）和垂直（y）方向上均具有大小，并且默认情况下将使用文件的固有尺寸进行显示
# 调整图像大小
如果把一张图片放在一个盒子里，而这张图片的原始长和宽比盒子的小或大，那么这张图要么缩在盒子里，要么就从盒子里面溢出。需要决定如何处理这样的溢出。

下面的示例中有两个盒子，长宽均为 200 像素：

- 一个包含了一张小于 200 像素的图像，它比盒子小，并且不会自动拉伸来充满盒子。
- 另一张图像大于 200 像素，溢出了盒子。
```
<div class="wrapper">
  <div class="box">
    <img
      alt="star"
      src="https://mdn.github.io/shared-assets/images/examples/big-star.png" />
  </div>
  <div class="box">
    <img
      alt="balloons"
      src="https://mdn.github.io/shared-assets/images/examples/balloons.jpg" />
  </div>
</div>
```
```
.wrapper {
  display: flex;
  align-items: flex-start;
}

.wrapper > * {
  margin: 20px;
}

.box {
  border: 5px solid darkblue;
  width: 200px;
}

img {
}
```

尝试向上面的示例中的 `<img>` 元素加入 max-width: 100%，会看到，左边那张小的图像没有变化，而大的图像变小了，恰好装在了盒子里

object-fit 属性可以被使用。当使用 object-fit 时，替换元素可以以多种方式被调整到合乎盒子的大小

- 下面的示例中使用了值**cover** 来缩小图像，同时维持了图像的原始比例。这样图像就可以充满盒子。但由于比例保持不变，图像多余的一部分将会被盒子**裁切掉**

- 如果使用值 **contain**，图像就会被缩放到足以完整地放到盒子里面的大小。如果它和盒子的比例不同，将会出现“开天窗”的结果。

- 对于 fill 值，它可以让图像充满盒子，但是不会维持比例
```
<div class="wrapper">
  <div class="box">
    <img
      alt="balloons"
      class="cover"
      src="https://mdn.github.io/shared-assets/images/examples/balloons.jpg" />
  </div>
  <div class="box">
    <img
      alt="balloons"
      class="contain"
      src="https://mdn.github.io/shared-assets/images/examples/balloons.jpg" />
  </div>
</div>
```
```
.wrapper {
  display: flex;
  align-items: flex-start;
}

.wrapper > * {
  margin: 20px;
}

.box {
  border: 5px solid darkblue;
  width: 200px;
  height: 200px;
}

img {
  height: 100%;
  width: 100%;
}

.cover {
  object-fit: cover;
}

.contain {
  object-fit: contain;
}
```
# 布局中的替换元素
在对替换元素使用各种 CSS 布局时，可能会发现他们的表现方式与其他元素有一些细节上的差异。例如，flex 或者 grid 布局中，默认情况下元素会被拉伸到充满整块区域。但是图像不会被拉伸，而会对齐到网格区域或者弹性容器的起始处。

可以在下面的示例中看到这一现象。该示例有一个两列两行的网格容器，里面有四个物件。所有的 `<div>` 元素有自己的背景色，被拉伸到充满了行和列。但是，图像并没有被拉伸

>替换元素在成为网格或者弹性布局的一部分时，有不同的默认行为

为了强制图像拉伸，以充满其所在的网格单元，必须做类似于下面的事情：
```
css
img {
  width: 100%;
  height: 100%;
}
```
这将会无条件地拉伸图像，所以很可能不会是我们想要的
