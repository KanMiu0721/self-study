# 什么是选择器？
CSS 选择器是 CSS 规则的第一部分。它是一种元素和其他术语的模式，告诉浏览器哪些 HTML 元素应在规则中应用 CSS 属性值。选择器选择的元素称为选择器的主语

## 类型选择器
类型选择器有时也称为标签名称选择器或元素选择器，因为它会选择文档中的HTML标签/元素

## 类选择器
类（class）选择器以点（.）字符开头。它会选择文档中所有应用该类的物品

## 特定元素的定向类
可以创建一个选择器，针对应用该类的特定元素，如span.highlight和h1.highlight

## 应用了多个类的元素
可以对一个元素应用多个类并单独定位，或者只有在选择器中所有类都存在时才选择该元素。这在构建可以以不同方式组合的组件时非常有用
```
HTML：

<div class="notebox">This is an informational note.</div>

<div class="notebox warning">This note shows a warning.</div>

<div class="notebox danger">This note shows danger!</div>

<div class="danger">
  This won't get styled — it also needs to have the notebox class
</div>

CSS：

body {
  font-family: sans-serif;
}

.notebox {
  border: 4px solid #666666;
  padding: 0.5em;
  margin: 0.5em;
}

.notebox.warning {
  border-color: orange;
  font-weight: bold;
}

.notebox.danger {
  border-color: red;
  font-weight: bold;
}

```
warning和danger在notebox的设置之下进一步增添粗体和颜色
## ID 选择器
大小写区分ID选择器以#字符开头，而非点字符，但其使用方式与类别选择器相同。区别在于ID每页只能使用一次，元素只能有一个值。ID选择器选择具有特定元素的元素，你可以在ID前加上类型选择器，仅在元素和ID匹配时才针对该元素
```
HTML:

<h1 id="heading">ID selector</h1>
<p>
  Veggies es bonus vobis, proinde vos postulo essum magis kohlrabi welsh onion
  daikon amaranth tatsoi tomatillo melon azuki bean garlic.
</p>

<p id="one">
  Gumbo beet greens corn soko <strong>endive</strong> gumbo gourd. Parsley
  shallot courgette tatsoi pea sprouts fava bean collard greens dandelion okra
  wakame tomato. Dandelion cucumber earthnut pea peanut soko zucchini.
</p>

CSS:

body {
  font-family: sans-serif;
}

#one {
  background-color: yellow;
}

h1#heading {
  color: rebeccapurple;
}
```
## 选择器列表
如果想对多个项目应用相同的CSS，可以将单个选择器合并成一个选择器列表
```
h1, 
.special {
  color: blue;
}
```

## 选择列表中的无效选择器:
当以这种方式分组选择器时，如果任何选择器在语法上无效，整个规则都会被忽略

```
CSS

h1 {
  color: blue;
}

..special {
  color: blue;
}
```

当两者合并时,整条规则被视为无效
```
h1, ..special {
  color: blue;
}
```

## 通用选择器
通用选择器用星号`*`表示。它选择文档中的所有元素。如果通过后代组合子串联，则选择该祖先元素内的所有元素
```
body {
  font-family: sans-serif;
}

* {
  margin: 0;
}
```

## 使用通用选择器让选择器更易读:

通用选择器的一个用途是使选择器更易阅读且更直观。例如，如果想选择一个元素中的第一个子节点（仅包括直接子节点）可以使用 ：first-child伪类
```
CSS

article :first-child {
  font-weight: bold;
}
```

选择`<article>`内的任何元素的第一个子元素
```
CSS

article *:first-child {
  font-weight: bold;
}

```
两者是等价的，但有些人觉得第二种方式更容易阅读
