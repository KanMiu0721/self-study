# 什么是选择器？
CSS 选择器是 CSS 规则的第一部分。它是一种元素和其他术语的模式，告诉浏览器哪些 HTML 元素应在规则中应用 CSS 属性值。选择器选择的元素称为选择器的主语

## 类型选择器
类型选择器有时也称为标签名称选择器或元素选择器，因为它会选择文档中的HTML标签/元素

## 类选择器
类（class）选择器以点（.）字符开头。它会选择文档中所有应用该类的物品

## 特定元素的定向类
可以创建一个选择器，针对应用该类的特定元素，如span.highlight和h1.highlight

## 应用了多个类的元素
可以对一个元素应用多个类并单独定位，或者只有在选择器中所有类都存在时才选择该元素。这在构建可以以不同方式组合的组件时非常有用
```
HTML：

<div class="notebox">This is an informational note.</div>

<div class="notebox warning">This note shows a warning.</div>

<div class="notebox danger">This note shows danger!</div>

<div class="danger">
  This won't get styled — it also needs to have the notebox class
</div>

CSS：

body {
  font-family: sans-serif;
}

.notebox {
  border: 4px solid #666666;
  padding: 0.5em;
  margin: 0.5em;
}

.notebox.warning {
  border-color: orange;
  font-weight: bold;
}

.notebox.danger {
  border-color: red;
  font-weight: bold;
}

```
warning和danger在notebox的设置之下进一步增添粗体和颜色
