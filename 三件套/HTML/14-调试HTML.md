# HTML与调试
HTML 本身不会出现语法错误，因为浏览器会宽松地解析它，这意味着即使源代码中有语法错误，页面仍然会显示。浏览器内置规则来说明如何解释错误的HTML标记（通常称为无效或格式错误的标记），并自动将其更改为有效的标记
## 使用 DOM 检测器:
所有现代浏览器都内置了一套开发者工具（devtools），提供检查当前标签页加载网页的功能

其一就是DOM检查器，它显示当前渲染的HTMLDOM并允许编辑

## 验证HTML文档
这项工作的工具是标记验证服务（Markup Validation Service，或称HTML验证器），由W3C创建和维护。验证器会接收一份HTML文档作为输入，逐一分析，并给一份报告，告诉HTML存在什么问题。
