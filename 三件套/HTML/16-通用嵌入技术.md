探讨一些允许将各种内容类型嵌入网页的元素：`<iframe>`、`<embed>`和`<object>`元素。`<iframe>`用于嵌入其他网页，另外两个则允许嵌入外部资源，如 PDF 文件
# 经典嵌入的应用
```
HTML:

<iframe
  src="https://developer.mozilla.org/en-US/docs/Glossary"
  width="100%"
  height="500"
  allowfullscreen
  sandbox>
</iframe>

CSS:

Copy
iframe {
  border: none;
}
```

- border: none
如果使用，`<iframe>`显示时没有周围边框。否则，默认情况下，浏览器会用边框显示`<iframe>`

- allowfullscreen
如果设置为全屏，`<iframe>`可以通过全屏API将它置于全屏模式

- src
该属性与`<video>`/`<img>`一样，包含指向待嵌入文档URL的路径

- width and height
指定了希望iframe的宽度和高度

- sandbox
该属性适用于比其他 `<iframe>` 功能稍现代的浏览器（例如 IE 10 及以上），要求更高的**安全**设置
如果绝对必要，可以逐一添加权限（在sandbox=""属性值内）。
一个重要的注意点是，绝不应在sandbox属性中同时添加allow-scripts和allow-same-origin——那样的话，嵌入内容可能会绕过阻止网站执行脚本的同源策略，从而用JavaScript完全关闭沙箱功能

# 使用 HTTPS
HTTPS是HTTP的加密版本。你应尽可能使用 HTTPS 来服务你的网站：

- HTTPS降低了远程内容在传输过程中被篡改的可能性。
- HTTPS防止嵌入内容访问父文档内容，反之亦然。

# `<embed>`和`<object>`元素
`<embed>`和`<object>`这些元素是用于嵌入外部内容（如PDF）的通用嵌入工具

但如果需要显示PDF，通常最好是链接到它们，而不是嵌入在页面里
```
<object data="my-pdf.pdf" type="application/pdf" width="800" height="1200">
  <p>
    You don't have a PDF plugin, but you can
    <a href="my-pdf.pdf">download the PDF file. </a>
  </p>
</object>
```
