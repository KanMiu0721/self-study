# 什么是矢量图形？
在网络上，一般使用两种类型的图像——光栅图像和矢量图像：
- 栅格图像是通过像素网格定义的——光栅图像文件包含每个像素应精确放置位置及其颜色的信息。流行的网页栅格格式包括位图Bitmap（.bmp）、PNG （.png）、JPEG（.jpg）和 GIF（.gif）
- 矢量图像是通过算法定义的——矢量图像文件包含形状和路径定义，计算机可以用来确定图像在屏幕上渲染时应呈现的样子。SVG格式使能够创建强大的矢量图形，供网络使用

# 什么是SVG？ 
SVG 是一种基于 XML 的语言，用于描述矢量图像。它基本上是标记，类似 HTML，只是你有许多不同的元素来定义你想在图片中出现的形状，以及你想应用的效果。SVG 是用来标记图形的，不是内容。SVG 定义了用于创建基础形状的元素，比如`<circle>`和`<rect>`，以及用于创建更复杂形状的元素，比如`<path>`和`<polygon>`。更高级的 SVG 功能包括 `<feColorMatrix>`（利用变换矩阵变换颜色）、`<animate>`（动画矢量图部分）和 `<mask>`（在图像上套用遮罩）
```
<svg
  version="1.1"
  baseProfile="full"
  width="300"
  height="200"
  xmlns="http://www.w3.org/2000/svg">
  <rect width="100%" height="100%" fill="black" />
  <circle cx="150" cy="100" r="90" fill="blue" />
</svg>
```
以上代码会生成一个圆和矩阵

制作SVG图像时，大多数人使用矢量图形编辑器，如Inkscape或Illustrator。这些软件包允许你使用各种图形工具制作各种插图，并制作照片的近似

# 向页面添加SVG
快速方法：img元素
要通过`<img>`元素嵌入SVG，只需在src属性中引用它你需要一个height属性或width属性（如果你的SVG本身没有长高比，则两者都用

### 优点
- 快速、熟悉的图像语法，内置文本对应功能，alt属性中提供

- 可以通过将`<img>`嵌套在`<a>`元素中，轻松将图片制作成超链接。

- 浏览器可以缓存SVG文件，从而使未来加载的图片页面加载速度更快。
### 缺点
- 无法用JavaScript操作图片。
- 如果想用 CSS 控制 SVG 内容，必须在 SVG 代码中包含内联 CSS 样式。（从 SVG 文件调用的外部样式表无效。）
- 不能用 CSS 伪类（比如 :focus）来重新设计图片。

## 故障排除与跨浏览器支持:
对于不支持 SVG 的浏览器（例如 8 及以下，Android 2.3 及以下），可以从 src 属性中引用 PNG 或 JPG，并使用 srcset 属性（只有新浏览器识别）来引用 SVG。这样只有支持的浏览器才会加载 SVG——旧浏览器则会加载 PNG
```
<img
  src="equilateral.png"
  alt="triangle with equal sides"
  srcset="equilateral.svg" />
```

也可以将SVG用作CSS背景图片
```
background: url("fallback.png") no-repeat center;
background-image: url("image.svg");
background-size: contain;
```

## 如何在HTML中包含SVG代码
也可以在文本编辑器中打开SVG文件，复制SVG代码，粘贴到HTML文档中——这有时称为将SVG内联化，或内联SVG。确保你的SVG代码片段以`<svg>`开始标签开头，以`</svg>`结束标签结束

```
<svg width="300" height="200">
  <rect width="100%" height="100%" fill="green" />
</svg>
```

### 优点
- 把SVG放在内联可以保存HTTP请求，因此可以稍微缩短加载时间。

- 可以为SVG元素分配class和id，并用CSS来做样式，无论是在SVG里还是放在HTML文档中CSS样式规则的地方。事实上，可以用任何SVG的呈现属性作为CSS属性

- 内联SVG是唯一允许在SVG图片上使用CSS交互（比如:focus）和CSS动画的方法（即使是在普通样式表中也是如此）

- 可以通过用`<a>`元素包裹SVG标记，把它变成超链接。
